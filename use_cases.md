# Use Cases

## Назначение документа

Документ содержит описание основных сценариев взаимодействия пользователей с информационной системой учета компьютерной и офисной техники.

---

# UC-001. Авторизация пользователя

## Цель

Предоставить пользователю доступ к системе в соответствии с его ролью.

## Акторы

- Пользователь

## Предусловия

- Пользователь зарегистрирован в системе.
- У пользователя есть логин и пароль.

## Основной сценарий

1. Пользователь открывает страницу авторизации.
2. Вводит логин и пароль.
3. Нажимает кнопку «Войти».
4. Система проверяет корректность учетных данных.
5. Система определяет роль пользователя.
6. Пользователь перенаправляется на главную страницу.

## Альтернативный сценарий

4а. Учетные данные неверны.

- Система отображает сообщение об ошибке.
- Пользователь остается на странице авторизации.

## Постусловия

Пользователь успешно авторизован в системе.

# UC-002. Добавление оборудования

## Цель

Зарегистрировать новую единицу оборудования.

## Акторы

- Сотрудник IT-отдела

## Предусловия

- Пользователь авторизован.
- Пользователь имеет необходимые права.

## Основной сценарий

1. Пользователь открывает раздел «Оборудование».
2. Нажимает кнопку «Добавить оборудование».
3. Заполняет форму.
4. Нажимает кнопку «Сохранить».
5. Система проверяет введенные данные.
6. Система сохраняет оборудование.
7. Новая запись появляется в общем списке.

## Альтернативный сценарий

5а. Инвентарный номер уже существует.

- Система выводит сообщение об ошибке.
- Сохранение не выполняется.

## Постусловия

Новое оборудование зарегистрировано.

---

# UC-003. Редактирование оборудования

## Цель

Изменить сведения об оборудовании.

## Акторы

- Сотрудник IT-отдела

## Предусловия

- Пользователь авторизован.
- Оборудование существует.

## Основной сценарий

1. Пользователь открывает карточку оборудования.
2. Нажимает «Редактировать».
3. Изменяет необходимые поля.
4. Нажимает «Сохранить».
5. Система проверяет данные.
6. Информация обновляется.

## Альтернативный сценарий

5а. Введены некорректные данные.

- Система отображает ошибки.
- Изменения не сохраняются.

## Постусловия

Карточка оборудования обновлена.

# UC-004. Передача оборудования

## Цель

Назначить нового ответственного сотрудника.

## Акторы

- Сотрудник IT-отдела

## Предусловия

- Пользователь авторизован.
- Оборудование зарегистрировано.

## Основной сценарий

1. Пользователь открывает карточку оборудования.
2. Выбирает действие «Передать».
3. Указывает нового ответственного.
4. При необходимости вводит комментарий.
5. Подтверждает передачу.
6. Система обновляет сведения об ответственном.
7. Система сохраняет запись в истории передач.

## Альтернативный сценарий

3а. Новый сотрудник не выбран.

- Система сообщает о необходимости выбрать сотрудника.

## Постусловия

Передача оборудования успешно зарегистрирована.

# UC-006. Импорт оборудования из Excel

## Цель

Добавить несколько единиц оборудования одновременно.

## Акторы

- Администратор

## Предусловия

- Пользователь авторизован.
- Подготовлен Excel-файл.

## Основной сценарий

1. Пользователь открывает раздел импорта.
2. Выбирает Excel-файл.
3. Запускает импорт.
4. Система проверяет структуру файла.
5. Система импортирует данные.
6. Отображается результат загрузки.

## Альтернативный сценарий

4а. Файл имеет неверный формат.

- Импорт отменяется.
- Пользователь получает сообщение об ошибке.

## Постусловия

Данные успешно загружены в систему.
