# Project Overview
### Информационная система учета компьютерной и офисной техники

## Общая информация

Название проекта: Информационная система учета компьютерной и офисной техники

Тип проекта: Веб-приложение

Предметная область: Управление ИТ-активами (IT Asset Management)

Статус проекта: Учебный проект, разработанный в рамках выпускной квалификационной работы

### Цель проекта - Разработать информационную систему, позволяющую автоматизировать процессы учета компьютерной и офисной техники организации, обеспечить централизованное хранение информации об оборудовании, контролировать его перемещение между сотрудниками и подразделениями, а также повысить качество управления материальными ресурсами.

### Проблема

Во многих организациях учет техники ведется с использованием электронных таблиц или нескольких несвязанных инструментов. Такой подход приводит к ряду проблем:
- отсутствию единой актуальной базы данных оборудования;
- сложностям при поиске информации;
- ошибкам при ручном вводе данных;
- отсутствию прозрачной истории перемещения техники;
- увеличению времени проведения инвентаризации.

Проект направлен на устранение этих недостатков за счет внедрения единой информационной системы.

### Решение

Разработанная система предоставляет единое пространство для хранения информации о компьютерной и офисной технике, позволяет управлять жизненным циклом оборудования и обеспечивает быстрый доступ к необходимым данным.

Основные возможности системы:
- регистрация оборудования;
- учет сотрудников и подразделений;
- назначение ответственных лиц;
- передача оборудования между сотрудниками;
- поиск и фильтрация данных;
- импорт информации из Excel;
- ведение журнала действий пользователей;
- разграничение прав доступа.

### Пользователи системы
| Роль |	Основные задачи |
| ----- | ---------------- |
| Администратор |	Управление пользователями, справочниками и настройками системы |
| Сотрудник IT-отдела |	Учет оборудования, регистрация техники, передача оборудования, формирование отчетов |
| Сотрудник организации |	Просмотр закрепленного за ним оборудования |

### Основные бизнес-процессы

Система автоматизирует следующие процессы:
- учет компьютерной техники;
- учет офисной техники;
- регистрация нового оборудования;
- передача оборудования между сотрудниками;
- изменение статуса оборудования;
- поиск информации об оборудовании;
- проведение инвентаризации.

### Архитектура решения

Система реализована как веб-приложение с трехуровневой архитектурой:

Клиентский уровень — пользовательский интерфейс.

Сервер приложений — обработка бизнес-логики.

База данных — хранение информации о пользователях, оборудовании и операциях.

### Используемые технологии
| Компонент |	Технология |
| -------- | ------------ |
| Backend |	Python, Flask |
| Database |	PostgreSQL |
| ORM |	SQLAlchemy |
| Frontend |	HTML, CSS, Bootstrap, Jinja2 |
| Version Control |	Git |
| Database Migration |	Flask-Migrate |

### Основные сущности системы

Система включает следующие ключевые сущности:
- Пользователь (User);
- Подразделение (Department);
- Оборудование (Equipment);
- Тип оборудования (Equipment Type);
- Передача оборудования (Transfer);
- Журнал действий (Action Log).

## Результаты проекта

В результате разработки была создана информационная система, позволяющая:
- автоматизировать учет оборудования;
- сократить время поиска информации;
- снизить вероятность ошибок при работе с данными;
- обеспечить контроль движения техники;
- централизовать хранение информации;
- разграничить права доступа пользователей.

### Перспективы развития
В дальнейшем проект может быть расширен за счет:
- интеграции с корпоративными информационными системами;
- уведомлений о завершении гарантийного срока оборудования;
- автоматизации проведения инвентаризации;
- поддержки штрихкодов и QR-кодов;
- интеграции со службами каталогов (например, LDAP/Active Directory).
