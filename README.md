# О проекте

Информационная система предназначена для автоматизации учета компьютерной и офисной техники организации.
Проект выполнен в рамках выпускной квалификационной работы по направлению «Математическое обеспечение и администрирование информационных систем».
В данном репозитории представлен не только программный код, но и комплект аналитической документации, демонстрирующий процесс проектирования информационной системы.

# Цели проекта
автоматизация учета техники;
хранение информации об оборудовании;
учет перемещения техники;
разграничение прав пользователей;
сокращение времени поиска информации;
повышение достоверности данных.
