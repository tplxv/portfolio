# Business Requirements
## 1. Общая информация
Название проекта - Информационная система учета компьютерной и офисной техники.
Цель проекта - Разработка информационной системы для автоматизации учета компьютерной и офисной техники организации, обеспечения централизованного хранения информации об оборудовании, контроля его состояния и перемещения между сотрудниками и подразделениями.

## 2. Описание проблемы
В организации учет компьютерной и офисной техники ведется с использованием нескольких разрозненных инструментов, что приводит к ряду проблем:
- отсутствие единого источника актуальной информации об оборудовании;
- сложности при поиске техники и определении ответственного сотрудника;
- недостаточная прозрачность процесса передачи оборудования между подразделениями;
- высокий риск возникновения ошибок при ручном вводе данных;
- отсутствие удобных инструментов поиска, фильтрации и формирования отчетов;
- увеличение времени на проведение инвентаризации.
В результате сотрудники ИТ-подразделения тратят значительное количество времени на поиск информации и актуализацию сведений о технике.

## 3. Бизнес-цели
Внедрение системы должно обеспечить:
- централизованный учет компьютерной и офисной техники;
- повышение достоверности информации;
- сокращение времени поиска оборудования;
- автоматизацию процессов учета и передачи техники;
- снижение количества ошибок при работе с данными;
- повышение эффективности проведения инвентаризации;
- разграничение доступа пользователей в соответствии с их ролями.

## 4. Заинтересованные стороны
| Роль  | Интерес |
| ------------- | ------------- |
| Руководство  | Получение актуальной информации об оборудовании и контроль использования ресурсов  |
| ИТ-отдел  | Ведение учета техники, регистрация оборудования, контроль перемещений  |
| Сотрудники организации | Просмотр закрепленного оборудования  |
| Администратор системы  | Управление пользователями, настройка справочников и контроль работы системы  |

## 5. Границы проекта
Входит в проект
- учет компьютерной техники;
- учет офисной техники;
- хранение характеристик оборудования;
- управление пользователями;
- управление подразделениями;
- учет передачи оборудования;
- поиск и фильтрация данных;
- расчет амортизации;
- ведение журнала действий пользователей.
Не входит в проект
- бухгалтерский учет;
- закупка оборудования;
- интеграция с внешними государственными информационными системами;
- автоматическое получение данных от производителей оборудования.

## 6. Критерии успешности проекта
Проект считается успешным, если система позволяет:
- хранить сведения обо всей компьютерной и офисной технике организации;
- выполнять поиск оборудования по различным параметрам;
- контролировать ответственных сотрудников;
- фиксировать историю перемещений техники;
- обеспечивать разграничение прав доступа;
- сократить время поиска информации по сравнению с ручным учетом.

## 7. Ограничения проекта
- система предназначена для использования во внутренней сети организации;
- доступ осуществляется только авторизованными пользователями;
- первоначальная загрузка данных выполняется из подготовленного Excel-файла;
- проект разработан как прототип и может быть доработан с учетом требований организации.

## 8. Риски проекта
| Риск  | Способ снижения |
| ------------- | ------------- |
| Некорректный ввод данных  | Проверка данных и обязательные поля  |
| Потеря информации  | Регулярное резервное копирование базы данных  |
| Недостаточная подготовка пользователей | Обучение и подготовка инструкции  |
| Недостаточная подготовка пользователей | Ведение актуальной документации и управление изменениями |
