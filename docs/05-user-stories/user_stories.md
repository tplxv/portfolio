# User Stories

## Назначение документа

Документ содержит пользовательские истории (User Stories), описывающие функциональные потребности пользователей информационной системы учета компьютерной и офисной техники.

Каждая история сформулирована по шаблону:

> **Как** <роль>, **я хочу** <действие>, **чтобы** <получить результат>.

---

## US-001. Авторизация в системе

**Как** пользователь,

**я хочу** авторизоваться в системе,

**чтобы** получить доступ к разрешенным функциям.

### Критерии приемки

- пользователь вводит логин и пароль;
- система проверяет учетные данные;
- при успешной авторизации открывается главная страница;
- при ошибке отображается соответствующее сообщение.

---

## US-002. Просмотр списка оборудования

**Как** сотрудник IT-отдела,

**я хочу** просматривать список оборудования,

**чтобы** быстро находить необходимую информацию.

### Критерии приемки

- отображается список оборудования;
- доступен поиск;
- доступна фильтрация;
- отображаются основные характеристики оборудования.

---

## US-003. Добавление нового оборудования

**Как** сотрудник IT-отдела,

**я хочу** зарегистрировать новую единицу оборудования,

**чтобы** она появилась в системе учета.

### Критерии приемки

- все обязательные поля должны быть заполнены;
- инвентарный номер должен быть уникальным;
- после сохранения оборудование отображается в общем списке.

---

## US-004. Редактирование оборудования

**Как** сотрудник IT-отдела,

**я хочу** изменять сведения об оборудовании,

**чтобы** поддерживать актуальность данных.

### Критерии приемки

- изменения сохраняются в базе данных;
- обновленная информация отображается пользователям;
- действие фиксируется в журнале.

---

## US-005. Передача оборудования

**Как** сотрудник IT-отдела,

**я хочу** передавать оборудование другому сотруднику,

**чтобы** информация об ответственном лице всегда была актуальной.

### Критерии приемки

- можно выбрать нового ответственного;
- фиксируется дата передачи;
- сохраняется предыдущий ответственный;
- операция отображается в истории перемещений.

---

## US-006. Просмотр истории перемещений

**Как** сотрудник IT-отдела,

**я хочу** видеть историю передачи оборудования,

**чтобы** отслеживать его перемещение между сотрудниками.

### Критерии приемки

- отображаются все операции передачи;
- для каждой операции указаны дата, отправитель и получатель;
- записи отсортированы по времени.

---

## US-007. Поиск оборудования

**Как** пользователь,

**я хочу** искать оборудование по различным параметрам,

**чтобы** быстро находить нужную единицу техники.

### Критерии приемки

Поиск выполняется по:

- инвентарному номеру;
- наименованию;
- модели;
- серийному номеру.

---

## US-008. Фильтрация оборудования

**Как** пользователь,

**я хочу** фильтровать оборудование,

**чтобы** просматривать только интересующие меня записи.

### Критерии приемки

Доступна фильтрация по:

- подразделению;
- категории;
- статусу;
- ответственному сотруднику;
- производителю.

---

## US-009. Импорт оборудования

**Как** администратор,

**я хочу** загружать оборудование из Excel,

**чтобы** быстро переносить большое количество данных.

### Критерии приемки

- пользователь выбирает Excel-файл;
- система проверяет корректность данных;
- новые записи добавляются в систему;
- ошибки загрузки отображаются пользователю.

---

## US-010. Управление пользователями

**Как** администратор,

**я хочу** создавать и редактировать учетные записи,

**чтобы** управлять доступом пользователей.

### Критерии приемки

Администратор может:

- создать пользователя;
- изменить сведения о пользователе;
- назначить роль;
- заблокировать учетную запись.

---

## US-011. Просмотр закрепленного оборудования

**Как** сотрудник организации,

**я хочу** видеть оборудование, закрепленное за мной,

**чтобы** получать актуальную информацию о выданной технике.

### Критерии приемки

- отображается только оборудование текущего пользователя;
- доступна карточка оборудования;
- редактирование недоступно.

---

## US-012. Просмотр журнала действий

**Как** администратор,

**я хочу** просматривать журнал действий пользователей,

**чтобы** контролировать изменения в системе.

### Критерии приемки

Журнал содержит:

- пользователя;
- дату и время;
- выполненное действие;
- объект изменения.
