# 🎯 Цель проекта

Разработать информационную систему, предназначенную для автоматизации учета компьютерной и офисной техники организации.

Система обеспечивает централизованное хранение информации об оборудовании, позволяет контролировать его состояние, отслеживать перемещения между сотрудниками и подразделениями, а также повышает эффективность управления ИТ-активами организации.

---

# ❗ Проблема

Во многих организациях учет оборудования ведется с использованием электронных таблиц или нескольких несвязанных между собой инструментов.

Такой подход приводит к следующим проблемам:

- отсутствие единого источника достоверной информации об оборудовании;
- сложности при поиске техники и ответственного сотрудника;
- высокий риск ошибок при ручном вводе данных;
- отсутствие истории перемещений оборудования;
- увеличение времени проведения инвентаризации;
- невозможность быстро сформировать необходимую отчетность.

Проект направлен на решение перечисленных проблем путем создания единой информационной системы учета оборудования.

---

# 💡 Решение

Разработанная система предоставляет единое пространство для хранения и управления информацией о компьютерной и офисной технике.

Основные возможности системы:

- регистрация оборудования;
- управление пользователями;
- управление подразделениями;
- назначение ответственных сотрудников;
- передача оборудования между сотрудниками;
- поиск и фильтрация данных;
- массовый импорт оборудования из Excel;
- ведение журнала действий пользователей;
- разграничение прав доступа.
