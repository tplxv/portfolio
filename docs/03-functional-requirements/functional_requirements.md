# Functional Requirements
## 1. Назначение документа
Документ содержит функциональные требования к информационной системе учета компьютерной и офисной техники. Требования определяют функциональность системы и являются основой для проектирования, разработки и тестирования.

## 2. Управление пользователями
FR-001. Авторизация пользователя
Описание
Система должна предоставлять пользователю возможность авторизации по логину и паролю.
Приоритет: Высокий

FR-002. Управление учетными записями
Система должна позволять администратору:
- создавать пользователей;
- изменять сведения о пользователях;
- блокировать учетные записи;
- назначать роли пользователям.
Приоритет: Высокий

FR-003. Ролевая модель
Система должна поддерживать следующие роли:
- Администратор;
- Сотрудник IT-отдела;
- Пользователь.
Права доступа определяются ролью пользователя.

## 3. Управление оборудованием
FR-004. Регистрация оборудования
Система должна позволять добавлять новую единицу техники.
Для каждой единицы оборудования должны храниться:
- инвентарный номер;
- наименование;
- тип техники;
- производитель;
- модель;
- серийный номер;
- статус;
- отдел;
- ответственный сотрудник;
- дата поступления;
- конец гарантии;
- полная амортизация;
- характеристики зависящие от типа оборудования.

FR-005. Просмотр оборудования
Пользователь должен иметь возможность просматривать карточку оборудования.
Карточка должна содержать всю информацию о выбранной единице техники.

FR-006. Редактирование оборудования
Пользователь с соответствующими правами должен иметь возможность изменять сведения об оборудовании.

FR-007. Удаление оборудования
Удаление оборудования должно быть доступно только администратору.

## 4. Поиск и фильтрация
FR-008. Поиск оборудования
Система должна обеспечивать поиск оборудования по:
- инвентарному номеру;
- названию;
- модели;
- серийному номеру.

FR-009. Фильтрация оборудования
Система должна поддерживать фильтрацию по:
- отделу;
- типу;
- статусу;
- статусу гарантии.

## 5. Передача оборудования
FR-010. Передача оборудования
Система должна предоставлять возможность передачи оборудования между сотрудниками.
При передаче должны сохраняться:
- дата передачи;
- предыдущий владелец;
- новый владелец;
- комментарий.

FR-011. История перемещений
Для каждой единицы техники система должна хранить историю всех передач.
История должна содержать:
- дату операции;
- пользователя;
- подразделение;
- комментарий.

## 6. Справочники
FR-012. Управление подразделениями
Администратор должен иметь возможность:
- создавать подразделения;
- редактировать подразделения;
- архивировать подразделения.

FR-013. Управление категориями оборудования
Администратор должен иметь возможность управлять перечнем категорий оборудования.

## 7. Импорт данных
FR-014. Импорт из Excel
Система должна поддерживать массовую загрузку оборудования из Excel-файла.
При загрузке должна выполняться проверка корректности данных.

## 8. Журнал действий
FR-015. Логирование
Система должна автоматически сохранять сведения о действиях пользователей.
Для каждого действия должны фиксироваться:
- пользователь;
- дата и время;
- выполненная операция;
- объект изменения.

## 9. Отчеты
FR-016. Формирование отчетов
Система должна предоставлять возможность формирования отчетов по:
- количеству оборудования;
- отделу;
- типам техники;
- статусам гарантии;
- статусам оборудования.

## 10. Общие требования
FR-017. Проверка данных
При вводе информации система должна выполнять:
- проверку обязательных полей;
- проверку уникальности инвентарного номера;
- проверку корректности формата данных.

FR-018. Разграничение доступа
Пользователь должен иметь доступ только к тем функциям, которые разрешены его ролью.
